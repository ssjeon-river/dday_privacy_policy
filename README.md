<h1>D-Day 카운터 개인정보처리방침</h1>
<p class="muted">시행일: 2026년 10월 1일</p>

<p>CEOLAB(이하 "개발자")은 Android 앱 <strong>D-Day 카운터</strong>(패키지명 app.ceolab.dday, 이하 "앱")를 제공하며, 이용자의 개인정보를 중요하게 생각합니다.</p>

<h2>1. 수집하는 개인정보</h2>
<p>앱은 어떠한 개인정보도 수집하지 않습니다. 회원가입이나 로그인 기능이 없으며, 이름, 연락처, 위치, 기기 식별자 등의 정보를 요청하거나 수집하지 않습니다.</p>

<h2>2. 앱에 저장되는 정보</h2>
<p>이용자가 입력한 D-Day 제목, 날짜, 색상 설정은 <strong>이용자의 기기 안에만</strong> 저장됩니다. 이 정보는 외부 서버로 전송되지 않으며, 개발자를 포함한 누구도 접근할 수 없습니다. 앱을 삭제하면 저장된 정보도 함께 삭제됩니다.</p>

<h2>3. 제3자 제공 및 광고</h2>
<p>앱은 인터넷 권한을 사용하지 않으며, 광고, 분석 도구, 제3자 SDK를 포함하지 않습니다. 따라서 어떠한 정보도 제3자에게 제공되지 않습니다.</p>

<h2>4. 아동의 개인정보</h2>
<p>앱은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.</p>
